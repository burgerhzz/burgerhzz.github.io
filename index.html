常見問題

需要哪個版本的 Premiere？

Premiere Pro 2020 以上，macOS。目前沒有 Windows 版。

可以裝在幾台電腦？

你自己的裝置都可以裝，沒有限制數量，也沒有啟用碼要輸入。

burgerGuide 的疊圖會被輸出出去嗎？

疊圖是放在最上層視訊軌的圖層，輸出前要關掉該軌道的眼睛， 否則會被算進成品。面板上有一鍵移除，安裝說明裡也寫得很清楚。 這是 Premiere 的限制——它的 API 沒有開放建立監視器參考線，所有同類工具都得這樣做。

平台改版之後安全區跑掉怎麼辦？

TikTok、Instagram、YouTube 都會改版面。我會跟著更新數值推新版， 你重新下載安裝即可，不另外收費。想自己微調的話，數值是明文寫在設定檔裡的。

burgerbo 可以下載別人的影片嗎？

技術上可以，但這個工具的用途是處理你自己上傳的影片、CC 授權素材、 或你已經取得授權的內容。下載他人受版權保護的影片可能違反 YouTube 服務條款， 後果由使用者自行承擔。
